# 使用指南

Halcyon 打开就是一间摄影棚，车停在中间。拖动旋转视角，滚轮或双指缩放。底部一排按钮控制车门、尾翼、灯光、拆解、气流、声音和视角；右侧面板是配置选项。

## 切换车型

页面左上角的 H9、G8、E4、R10 切换车型。车会在原地拆掉重建，每款车各自记住上次的配置。也可以用链接直接打开某款车：`https://racing.ticoag.fun/?car=g8`。

## 配置

右侧面板分为六个标签：

- **风格**：每款车的成套预设，一次换好全部选项。
- **漆面**：10 种颜色，7 种涂层（金属、珠光、高光、哑光、镜面、变色龙、碳纤维）。
- **轮毂**：4 种样式，5 种轮毂涂层，6 种卡钳颜色。
- **套件**：鹅颈尾翼、主动扰流或无尾翼；赛道套件或公路套件。
- **涂装**：纯色、双条纹、偏置条纹、双色、斜环。
- **内饰**：碳黑、赛道红、马鞍棕、象牙白。

## 用链接分享配置

车型和配置都可以写进链接，打开就是那一套：

`https://racing.ticoag.fun/?car=g8&paint=lava&finish=matte&wheel=mesh&wing=none`

{{options}}

没有写出的选项使用该车型的第一套预设。

## 拆解（零件仓库）

车停着的时候，“分解”按钮把整车拆开，零件按九个系统摆在地面的九个区域里：车身、车门、座舱盖、空力、座舱、车轮、车尾、悬架、动力总成。再按一次装回去。拆开后，每个系统有自己的按钮，可以单独装上或卸下。

![Halcyon H9 拆解后的零件按九个系统摆在摄影棚地面上](/img/parts.jpg)

指针移到零件上会显示它的名称。点击任意零件把它拿起来：零件升到视线高度，镜头靠近，背景变暗；拖动可以转动零件，缩放可以看清漆面颗粒、碳纤维纹理和缝线。点旁边空白处或按 `Esc` 放回。

## 驾驶程序

三个自动演示程序都在程序化生成的夜间赛道上进行，摄影棚会从车底融化成赛道，车停下后再变回来：

- **巡航**：弹射起步，一路加速到极速并保持。
- **过弯**：在抓地极限下通过高速 S 弯，压过弯心的路肩。
- **制动**：直道全油门，然后全力制动进入发夹弯。

屏幕上显示车速、挡位、转速、g 值，以及下压力、阻力和前轴下压力占比。

## 自由驾驶

“自由驾驶”把车从摄影棚带到一条 10 公里公路赛道的发车格上，白天，手动驾驶。地图 4 公里见方：1.4 公里的大直道穿过体育场，沿湖的高速弯，三个发夹弯爬上海拔 116 米的山口，下山穿过森林，共 21 个弯。

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` 或方向键 | 油门、转向、制动（静止时按制动键倒车） |
| `空格` | 手刹 |
| `C` | 切换视角：近追尾、远追尾、驾驶座 |
| `B` | 回头看 |
| `R` | 回到路上 |
| `T` | 开关驾驶辅助（ABS、牵引力控制、车身稳定） |
| `P` | 自动驾驶 |
| `N` | 切换时间：黄昏、白天、夜晚 |
| `Esc` | 停车并返回摄影棚 |

手柄一经触碰即接管：左摇杆转向，扳机油门和制动，A 手刹，Y 视角，X 复位，B 回头看，右摇杆环视。触屏设备会出现转向盘和踏板。

冲过起点线开始计圈，通过全部分段才算一圈。屏幕上还有赛道小地图、最快圈速、大直道测速点，以及漂移和飞跃的提示。关闭驾驶辅助后可以漂移。

## 气流

“气流”按钮打开风洞视图：烟流绕过车身、从车尾分离、形成尾流，翼尖涡清晰可见。车身表面的颜色是压力系数 Cp。尾翼升降或空气刹车立起时，流场随之改变。不支持所需 GPU 特性的设备会自动改用二维流线图。

## 声音

声音默认关闭，点“声音”按钮打开。摄影棚里有背景音乐；启动驾驶程序后是引擎、排气、进气、风噪和轮胎的声音，在驾驶座视角里会变得沉闷。

## 常见问题

### Halcyon 是什么？

Halcyon 是一个在浏览器里运行的 3D 跑车配置器和驾驶模拟。四款车（H9、G8、E4、R10）完全由代码程序化生成，没有使用任何 3D 模型文件，用 three.js 实时渲染。

### 这些车是真实存在的吗？

不是。H9、G8、E4、R10 都是为这个项目原创设计的虚构车型，与任何真实汽车厂商无关。它们的参数是模拟里的设定，以及在模拟中实际跑出来的结果。

### 需要付费、安装或注册吗？

都不需要。Halcyon 是免费的网页，打开 https://racing.ticoag.fun 就能用，没有账号，也没有广告。

### 需要什么设备和浏览器？

支持 WebGL 2 的现代浏览器，电脑和手机都可以。三维风洞需要浮点渲染目标等 GPU 特性，不支持时自动改用二维流线图。显卡越好，画面越流畅。

### 手机上能自由驾驶吗？

可以。触屏设备上会出现转向盘、油门和制动踏板、手刹，以及视角、复位、退出按钮。

### 风洞是真实计算的吗？

是的。气流视图是在 GPU 上实时求解的三维格子玻尔兹曼（D3Q19）流场，带大涡模拟湍流模型，约 56 万个网格单元，不是预先录制的动画。用同样的求解器设置计算方板的阻力系数得到 0.95，实测值为 1.17。

### 引擎声是录音吗？

不是。引擎声按曲轴转角和每款车的点火顺序在 AudioWorklet 中实时合成，所以 V12、十字曲轴 V8 和 V10 的声音各不相同；电动的 E4 则是电机转速的阶次声。

### 哪款车最快？

极速最高的是 H9（400 km/h）；加速最快的是 E4（0–100 km/h 1.9 秒）；过弯最快的是 R10（3.4 g）。

### 它是开源的吗？

源代码公开在 GitHub：https://github.com/ticoAg/racing
